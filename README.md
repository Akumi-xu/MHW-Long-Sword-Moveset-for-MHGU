# 公会太刀 · 世界招式移植 v1.0.8

本页对应内部v13。另一条v11优化、保留v13刀线分支以v1.1发布，两版的兜割命中特效和受击结算机制不同。

## 版本对应

v1.0.8 = 内部 v13。在该内部基线最后追加默认特殊纳刀术3速度；版本号保持，资源与基线逐文件一致。

## 最终调整

特殊纳刀默认内置世界纳刀术3速度：起手有效阶段1.16倍，无需收刀技能；GU收刀术不重复叠加。后段等待、居合反击窗口和其他招式参数保持。

PC副本已测无技能与四种收刀技能来源：起手均1.16倍、后段均1倍。普通收刀仍由GU处理。

## 更新与差异

以内部 v13为基线，追加默认纳刀术3速度。
- 气刃突刺、兜割和大居合采用以1.0.1为基础调整的音画；突刺刀身红线更明显并加长，大居合第二道刀线加长，保留此前对照世界调整的时机及消散。
- 兜割使用樱花气刃斩的三组原生命中特效，缩放0.45，去除额外白色挥刀弧；下劈垂直红线保留。
- 保留自动下劈、手动下劈及跳跃/上坡气刃后的派生。
- 保留v12的受击独立结算：下劈已经触发后，进入已覆盖的原生受击状态，剩余延迟伤害、命中特效及音效继续推进。死亡、换区或目标失效仍清理任务。

验证：既有PC0.16.0副本存档记录覆盖四刃色突刺、三种开刃大居合音画、自动兜割七次真实扣血，以及受击状态中的七次樱花命中特效。受击测试包含夹具切换，未逐个覆盖怪物攻击、眩晕及所有异常。

## 安装与操作

PC安装：关闭游戏，先把旧版MHW_WORLD_DEV整个移出mods，再将本包romfs放入游戏目录mods/MHW_WORLD_DEV/。不要直接叠加旧版残留文件，不要同时启用另一份公会太刀或其他太刀动作/派生MOD。使用公会风格太刀。
操作（GU按键）：攻击中R+A看破斩、R+B特殊纳刀、R+X气刃突刺；纳刀后X小居合、R大居合；开刃突刺命中起跳后可自动下劈或按R手动下劈。
参数：无新增配置菜单或外置ini；默认数值已包含在插件中，修改源码后可重新构建。
限制：主要验证MHGURecomp 0.16.0；本次未做安卓、模拟器或实机验收，也未重新覆盖所有第三方MOD组合；并非世界画面的完全还原。
卸载：关闭游戏，将mods/MHW_WORLD_DEV移出。存档与游戏配置无需改动。
