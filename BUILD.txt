世界风格 v1.2-Recomp 构建

在 ASCII 路径下保留此工程目录结构。使用 Windows Rust nightly（2026-10-24），rust-src，cargo-mhgu-forge 1.5.0，ARM GCC xPack 15.2.1-1.1 和 Python 3。将 ARM GCC 的 bin 目录放进 PATH，或设置 ARM_GCC 指向编译器，链接器也需在 PATH 中可用。
运行 build.ps1。构建产物在 01_plugins/mhw_ls_rebuild/mhw_ls_rebuild.nro，脚本同时检查重定位。
默认关闭逐采样输入诊断。需要命令日志时在构建前设置 ML_WORLD_INPUT_TRACE=1。
配对资源使用 v1.2-Recomp 安装包里的 ARC。重编译只替换 romfs/nativeNX/plugins/mhw_ls_rebuild.nro。

Repack: python repack.py MHGU_WORLD_STYLE_v1.2-Recomp.zip 01_plugins/mhw_ls_rebuild/mhw_ls_rebuild.nro MyBuild.zip
